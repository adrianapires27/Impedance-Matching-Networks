# Impedance Matching Networks Design and Analysis

## Project Overview

This project focuses on the design, analytical analysis and simulation of impedance matching networks operating at **962 MHz**, developed as part of the Project of Wave Networks and Electronics (PROE) course at the University of Aveiro.

The main objective was to design and evaluate different impedance matching solutions for a complex load impedance:

Z_L = 71.1 + j51.1 ohm

Several matching network configurations were studied, combining theoretical calculations, Smith Chart analysis, MATLAB scripts and circuit simulations using Qucs.

## Project Objectives

- Analyse the complex load impedance at 962 MHz.
- Design different impedance matching networks.
- Perform analytical calculations using transmission line theory.
- Use Smith Charts to determine matching solutions.
- Simulate the proposed circuits and validate the theoretical results.
- Compare different matching network configurations.

## Impedance Matching Solutions

Three matching configurations were studied:

### System 2 – Open-Circuit Stub

An open-circuit stub matching network was designed to compensate for the reactive component of the load and achieve impedance matching.

### System 5 – Series Inductor

A series inductance was used as a matching element to compensate for the load reactance and obtain the desired impedance.

### System 7 – Quarter-Wave Transformer

A quarter-wave transformer (\(\lambda/4\)) was designed at a voltage minimum point to achieve impedance transformation.

## Design and Simulation Methodology

The project combined theoretical analysis and circuit simulation.

The design process involved:

1. Characterization of the complex load impedance.
2. Analytical calculation of the matching network parameters.
3. Smith Chart analysis to determine the required matching elements.
4. Implementation and simulation of the proposed circuits using Qucs.
5. Comparison and validation of theoretical and simulation results.
